# Splendor art assets

Every image here was **newly generated with local AI image generation**. The scans of the physical game (in Joe's vault) were used only as visual reference when writing prompts. No scan pixels ship.

## Library (each asset generated once, reused everywhere)
- `gems/{white,blue,green,red,black,gold}.webp`: transparent, 512², the gem fitted to a 448 box. **The only gem art in the game.** Used on card corners, cost pips, tokens, noble chips, bonus counters and phone chips.
- `scenes/t{1,2,3}-{white,blue,green,red,black}.webp`: card scene paintings, 630×880 (63:88). Several cards of the same tier and color share a scene.
- `nobles/n-01..n-10.webp`: noble portraits, 512², in the same order as the nobles in the card-data note.
- `backs/engraving.webp`: grayscale quill engraving, 630×880. Tint it per tier in CSS (green / amber / blue).
- `backs/noble-engraving.webp`: grayscale horseman engraving, 512². Tint it brown.
- `token/parchment.webp`: the token-center texture, 256². The colored rim is CSS.
- `table/surface.webp`: a seamless walnut tile, 1024² (mirror-tiled, so it repeats cleanly).
- `sounds/*.mp3`: synthesized effects. See `sounds/CREDITS.md`.

## Models
- **Flux** (`fluxedUpFluxNSFW_112_fp8.safetensors` + `clip_l` + `t5xxl_fp8_e4m3fn` + `ae`): euler/simple, 20 steps, guidance 3.5. Used for the **gems** and the **table** texture (photoreal suits them).
- **SDXL base 1.0**: dpmpp_2m/karras, 30 steps, cfg 6.5, with a negative prompt (no nudity, text or frames). Used for the **scenes, nobles, engravings and parchment**. Painterly output matches the real cards better.
  - Flux is not used for people: that checkpoint is NSFW-tuned and produced nudity on noble portraits, and it tended to add fake card frames and garbled text to scenes.

## Regenerate
1. Start ComfyUI on the 7900 XT **with `--disable-smart-memory --fp32-vae`**:
   ```
   ~/ai/ComfyUI/start.sh --listen 127.0.0.1 --port 8188 --reserve-vram 2.0 --fp32-vae --disable-smart-memory
   ```
   Without `--disable-smart-memory`, ROCm produced corrupted (NaN or noise) images after a few generations.
2. Generate the raw images: `python tools/splendor-art/comfy_gen.py tools/splendor-art/jobs.json /tmp/splendor-raw [--only name1,name2]`.
3. Process them: `python tools/splendor-art/process_assets.py /tmp/splendor-raw client/src/games/splendor/assets`. This needs `rembg[cpu]`, pillow and numpy, ideally in a separate venv. **Don't** install rembg into the ComfyUI venv, because its numpy pin breaks it.
4. **Always look at the outputs.** Reject garbled text, frames, nudity and anatomy errors.
5. Stop ComfyUI when done.

API-format workflows: `tools/splendor-art/workflow-flux-api.json` and `workflow-sdxl-api.json`.
